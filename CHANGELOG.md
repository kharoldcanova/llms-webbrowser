# Changelog

## [0.1.0] - 2026-10-27

### Añadido

- Laboratorio de `runonweb` con Vite como servidor y bundler.
- Demo de texto a emojis (`runonweb/emoji`).
- Demo de similitud de embeddings con similitud coseno (`runonweb/embed`).
- Demo de eliminación de fondo con subida de imagen y comparación original/resultado (`runonweb/remove-bg`).
- Badge de dispositivo resuelto (WebGPU, f16 o WASM) y progreso de descarga por tarjeta.
- Documentación base: `README.md`, `AGENTS.md`, `STATE.md`, `.gitignore`.
